# Publication Artifact Provenance Ledger

**Originally opened:** July 28, 2026  
**Last reconciled:** August 9, 2026

This ledger follows the repository source-of-truth order and distinguishes byte-original experiment artifacts, deterministic derived evidence, transparent notebook/log reconstructions, and unresolved historical provenance.

## Status Definitions

- **Original local:** byte-level JSON/checkpoint produced by the experiment and present locally.
- **Derived:** deterministically generated from validated local artifacts without training.
- **Reconstructed:** metrics recovered from captured notebook/log output; not promoted to byte-original status.
- **Unresolved:** source artifact or required author confirmation is not available.

## Submission Policy

Reconstructed V7 artifacts may support transparently qualified engineering claims, but must never be described as raw/original JSON. The submission archive should contain the reconciliation/manifest records and all legally shareable original artifacts. Dataset hashes identify the exact local snapshot without redistributing the licensed images.
